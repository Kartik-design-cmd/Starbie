# Starbie
Custom PCB and firmware project for Starbie

About the Project

Starbie is a custom electronics project built around a small microcontroller, an OLED display, and sensors. The goal is to create a personalized device with an interactive menu and visual reactions.

Hardware Components

- Seeed XIAO ESP32-C3 microcontroller
- 0.96-inch OLED display
- MPU6050 accelerometer and gyroscope
- DHT11 temperature and humidity sensor
- Two push buttons
- 10K resistor

PCB Design

I designed the schematic and PCB layout using KiCad. I created a custom board outline, routed the electrical connections, added a GND copper zone, and checked the design using the Design Rules Checker (DRC).

Firmware

The firmware is based on the starter code provided in the Starbie project guide. I configured the pin settings, worked on the available customization options, and troubleshot errors in Arduino IDE.

Current Status

The PCB design and initial firmware preparation are complete. The next stage is manufacturing the PCB, assembling the hardware, and testing the firmware with the physical components.
